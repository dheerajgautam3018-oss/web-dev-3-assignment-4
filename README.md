# Inventory & Data Management System

## Setup & Run
1. Extract this folder and open it in your terminal:
   ```bash
   cd inventory-management-api
   ```
2. Install dependencies:
   ```bash
   npm install
   ```
3. Ensure MongoDB is running locally on `mongodb://127.0.0.1:27017/inventory_db` (or update `.env`).
4. Start the server:
   ```bash
   npm start
   ```
